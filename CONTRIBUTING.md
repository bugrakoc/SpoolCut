# Contributing to SpoolCut

A short [compatibility report](docs/TESTING.md#submit-a-compatibility-report)
helps even if every test you ran passed. Use Issues for reproducible bugs
and concrete feature requests. Use Discussions for compatibility results,
questions and early ideas.

For bugs, include the SpoolCut version, the smallest steps that reproduce
it, the expected and observed results, and any relevant footage characteristics.
Use **Help → System Information** if you want to attach the local report.
Describe sources generically and share sample video only if you have
permission to share it. Project JSON files, logs and screenshots can
contain private paths and names.

For a code contribution, use the [build and test instructions](README.md#build-and-test)
and open a pull request with the behavior you changed and the checks you
ran. Include a reproducible test for an editing or export regression.
See the [roadmap](ROADMAP_PUBLIC_TESTING.md) for the current milestone.
