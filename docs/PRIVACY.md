# SpoolCut privacy

SpoolCut has no automatic telemetry, analytics, crash uploads, installation
IDs or automatic compatibility reporting. It does not prompt you to report
an export. Editing and stream-copy export run locally.

**Help → System Information** collects details when you open the dialog.
It uses the operating system, the current preview session and the local
multimedia libraries and tools. It runs the configured FFmpeg and FFprobe
executables with their version option and displays only their version tokens.
Data that cannot be identified reliably is marked **Unknown or unavailable**.
On Linux, RAM is the usable total reported by the OS. GPU names depend on
the host's local PCI name database. The OpenGL fields describe the app's
active context and can identify a software OpenGL implementation.

The report includes only application and build details, OS and session
information, hardware model names, RAM, driver and renderer information,
and multimedia versions. The report omits usernames, hostnames, IP and
MAC addresses, serial numbers, device identifiers, media content, media
metadata, personal filenames and paths, and environment dumps. The app
does not save the report or send it anywhere. **Copy Information** copies
the visible report to your system clipboard, which your desktop or clipboard
manager may retain or sync under its own settings.

Help links open your browser when you select them. A report reaches GitHub
only if you submit it yourself. Review anything you add to a public report,
especially screenshots, crash logs and project files. SpoolCut project
files store source paths so the project can reopen its media. GitHub handles
visits and submissions under its own privacy policy.
