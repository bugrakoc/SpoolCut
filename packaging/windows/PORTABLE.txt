SpoolCut portable for Windows 11 x86-64

Extract the complete ZIP. Open SpoolCut/bin/SpoolCut.exe from the extracted
folder. Keep the files under bin together. Qt, libmpv, FFmpeg and FFprobe are
bundled. The desktop defaults to software rendering. Set
SPOOLCUT_QT_PREVIEW=opengl before launching to try the OpenGL preview.

The CLI is SpoolCut/bin/spoolcut-cli.exe. Run it with --help for usage.
Projects and source media can live outside the extracted folder.

LICENSE contains the SpoolCut GPLv3 license. Third-party notices are under
share/licenses. MSYS2-packages.tsv identifies exact binary and source
packages. The matching Windows-sources archive is published alongside
each distributed binary and includes source-revision.txt.
